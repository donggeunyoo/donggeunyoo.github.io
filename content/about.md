I contribute to the Linux kernel's DRM graphics stack — the GPU scheduler
(`drivers/gpu/drm/scheduler`) and the AMD (`drivers/gpu/drm/amd/amdgpu`) and
Broadcom V3D (`drivers/gpu/drm/v3d`) drivers. I find bugs, send the fixes
upstream, and write here about how they actually work: the code path, the race
or lifetime problem underneath, and what the review turned up.

The posts aim to be precise rather than introductory. If something here is
wrong, tell me.
