I contribute to the Linux kernel — mostly the DRM GPU scheduler
(`drivers/gpu/drm/scheduler`) and adjacent drivers. I find bugs, send the
fixes upstream, and write here about how the fixes actually work: the code
path, the race or lifetime problem underneath, and what the review turned up.

The posts aim to be precise rather than introductory. If something here is
wrong, tell me.
